📌 About the Project

Python Projects is a growing collection of beginner-friendly Python applications created to practice programming, explore useful libraries, and build practical software.

The repository includes desktop utilities, automation tools, audio applications, QR code generation, and interactive games.

Each project focuses on a specific task, making it easier to explore the code, understand the implementation, and experiment with new ideas.

🎯 Project Goals

- 🧠 Strengthen Python programming fundamentals.
- 🛠️ Build practical applications instead of only writing theory.
- ⚙️ Explore automation and third-party libraries.
- 🎮 Create interactive games and fun programming projects.
- 📈 Continuously improve code quality and project documentation.

💻 Getting Started

Prerequisites

Before running the projects, make sure you have:

- Python installed on your computer.
- Git installed if you want to clone the repository.
- A terminal such as PowerShell, Command Prompt, or a terminal inside your IDE.

Check your Python installation:

python --version

If "python" is not recognized on Windows, try:

py --version

Clone the Repository

git clone https://github.com/Omrawat11/PYTHON_PROJECTS.git
cd PYTHON_PROJECTS

---

▶️ Installation and Usage

Each project may have different dependencies. Install only the packages required by the project you want to run.

1. Battery Notification

cd "Battery Notification"
python -m pip install psutil win10toast
python Battery_Notification.py

2. QR Code Generator

cd "QR Code"
python -m pip install qrcode[pil]
python qr_code.py

3. Text to Speech

cd "Text to speech"
python -m pip install gTTS
python text_to_speech.py

4. Turtle Racing

Run the following command from the project directory containing the script:

python turtle_racing.py

The "turtle" module is included with standard Python installations, although some Python installations may require additional Tcl/Tk support.

5. Rock Paper Scissors

Run this command from the repository root:

python Rock_Paper_Scissors.py

6. Audio Book

Open the "Audio Book" directory and check the actual Python entry-point filename and dependencies before running it.

Note: The script names above should match the files in the repository. If any filename differs, replace it with the actual filename. Some projects may also require an internet connection, such as projects using Google Text-to-Speech.
