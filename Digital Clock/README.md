# ⏰ Modern Digital Clock

A sleek, responsive desktop digital clock with vibrant neon/dark visual themes, 12H/24H formats, window pinning, and keyboard shortcuts built in Python using Tkinter.

---

## ✨ Features

- **🎨 5 Curated Color Themes**:
  - **Cyber Cyan**: Sleek futuristic neon cyan with deep slate background.
  - **Matrix Emerald**: Phosphor terminal green on deep black.
  - **Solar Amber**: Warm retro digital amber glow.
  - **Electric Violet**: Vivid cyberpunk purple and magenta.
  - **Ice White**: Minimalist crisp white and subtle slate.
- **🕒 12-Hour / 24-Hour Toggle**: Seamlessly switch between standard 12-hour format (with AM/PM badge) and 24-hour military time.
- **📅 Full Calendar Date & Info**:
  - Day of the week and full date (e.g., `Wednesday • 02 September 2026`).
  - Day of year and Week number tracking.
- **📌 Always-on-Top Pinning**: Float the clock on top of other windows while working, gaming, or coding.
- **⚡ Anti-Jitter Typography**: Uses fixed-pitch `Consolas` glyph spacing so digits do not shake or wobble as seconds increment.
- **🎯 Auto-Centered**: Launches centered on your desktop display automatically.
- **⌨️ Keyboard Shortcuts**:
  - <kbd>T</kbd> : Cycle theme
  - <kbd>F</kbd> : Toggle 12H / 24H mode
  - <kbd>P</kbd> : Toggle Always on Top (Pin)
  - <kbd>Esc</kbd> : Quit application

---

## 🚀 How to Run

No external third-party dependencies required! Built entirely using Python's standard library.

```bash
python clock.py
```
